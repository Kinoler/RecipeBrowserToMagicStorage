Allows you to filter items in your magic storage according to the selected item in the Recipe browser.

Recipe browser window:
Select the item holding the Ctrl while any of recipe browser's (Recipe, Ingrigient or Items) window is open. (Key can be changed in settings)

Magic storage window:
Filter items if any of the crafting or the storage panel is open.


By default the mod filters the items by clicking on item only if the filter hot key is pressed in that moment. This behaviour can be changed in the config.

In case of you encounter any errors or incompatible TML version issue, please don't hesitate to create a ticket in my GitHub repository https://github.com/Kinoler/RecipeBrowserToMagicStorage/issues, specifying your exact version of Terraria and TML.
